# KABA Platform API

## Current endpoints

### GET /

Returns basic service information.

### GET /health

Returns the current health status and timestamp.

## Planned endpoints

- List categories
- Search products
- Read a product
- Create a draft product
- Update a product
- Upload product images
- Update stock
- Activate or deactivate a product

## Security

The public API will require its own authentication and will not expose PrestaShop credentials or access tokens.
